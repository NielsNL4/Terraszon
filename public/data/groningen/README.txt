Tree records use the official Groningen WFS and are normalized to estimated
height/crown/profile records. Estimates are not measurements.

The datasets are separate files, not relicensed as one merged database.
manifest.json records source, capture time, validity, extent, counts and SHA-256.
Refresh is manual. Only complete bounded snapshots are published.
Run: npm run data:refresh
Build/publication does not download public source data automatically.
